Work

Office tools, included

Nothing to install before your first day of work.

WPS Office — documents, spreadsheets, presentations; opens Word/Excel/PowerPoint files well.
Firefox — web browser.
Flameshot screenshots (Print Screen) · CopyQ clipboard manager.
Tiếng Việt

Vietnamese typing, ready at login

The input method is preinstalled and enabled (Telex) — no setup needed.

Press the ` key (left of 1) to toggle Vietnamese typing.
Prefer a Vietnamese interface? Menu → Languages → Tiếng Việt — everything is preinstalled.
Maintenance

Updates itself — hands off

The system receives software and configuration updates automatically every day.

Updates run in the background and never interrupt your work.
Something wrong? Contact the IT team — no need to fix things yourself.
