Welcome to Sai

Your computer is ready — six things worth knowing.

🟦 The S button = Start

Bottom-left corner, just like Windows. Click it to find and launch any app — type to search.

📁 Files = File Explorer

Press ⊞ Super + E to open, same as Windows+E. Documents, Downloads — all in the left sidebar.

⌨️ Typing Vietnamese

Built in and ready (Telex). Press ` (left of the 1 key) to toggle. Works in every app, whatever the display language.

📸 Screenshots

Press PrtSc or ⊞ Super+Shift+S — select an area, annotate, save or copy. Like Snipping Tool.

📊 Task Manager

App frozen? Press Ctrl+Shift+Esc to open the task manager and end it — old habits welcome.

🌐 Prefer Vietnamese?

Menu → Languages → add Tiếng Việt and move it to the top, then log out and back in. Everything is preinstalled.

Updates install automatically every day — nothing to do. Having trouble? Contact the IT team.
